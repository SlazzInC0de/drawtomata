# Security Policy

## Supported Versions

Only the latest version deployed from the `main` branch is supported with security updates.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Report them privately via email to **vsuryansh080405@gmail.com** with:

- A description of the issue and its potential impact
- Steps to reproduce (URL, input, browser)
- Any proof of concept, if available

You can expect an acknowledgement within 72 hours. Valid reports will be fixed as soon as possible, and you will be credited in the release notes if you wish.

## Scope

Drawtomata is a fully client-side tool. In-scope issues include XSS, malicious input handling in the parsers/converters, and dependency vulnerabilities.
